# Output Formats

Choose the export format based on how the report will be consumed.

## DOCX (default)
- Best for: editable deliverables, drafts shared for review, printed packets.
- Template: `assets/templates/default-report-template.docx`.
- Use when the reader will iterate on the document.

## PDF
- Best for: final, read-only distribution (board decks, client deliverables).
- Generate from the DOCX via the document exporter; keep the same template styling.

## PPTX
- Best for: verbal walkthroughs, all-hands, investor calls.
- Use a slide-per-section structure: title, one insight + one chart per slide,
  closing takeaways. Keep text minimal — the speaker carries the detail.

## Format selection rule
If the audience is **executive or external** → PPTX or PDF.
If the audience is **internal or reviewing** → DOCX.
When unsure, default to DOCX so the recipient can edit.
