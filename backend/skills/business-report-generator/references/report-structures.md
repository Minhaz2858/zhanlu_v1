# Report Structures

Match the section layout to the audience. Every structure starts with an
Executive Summary and ends with Next Steps.

## 1. Executive Brief (for CEO / leadership)
- Executive Summary (3 bullets max)
- Headline Metrics (Table: metric, this period, last period, Δ%)
- Top 3 Insights
- Risks & Watch-items
- Recommended Actions

## 2. Operational Weekly (for team leads)
- Period & Scope
- What Happened (narrative + charts)
- Metrics Deep-dive (by segment / region / product)
- Blockers & Dependencies
- Next Week Plan

## 3. Board / Investor (QBR)
- Executive Summary
- Business Highlights (with chart)
- Financial Performance (with chart)
- Strategic Initiatives Progress
- Risks & Mitigations
- Asks / Decisions Needed

## Guidance
- One chart per insight — never a chart without a takeaway sentence.
- Keep sections under 150 words; link detail to an appendix if needed.
- Deltas must be sign-labeled (+ / −) and relative to the prior comparable period.
